# Omaha 1944

FPS nel browser che simula lo sbarco in Normandia (6 giugno 1944): dal bombardamento delle corazzate all'assalto dei bunker MG42 sulla scogliera di Omaha Beach.

## Come giocare
Apri `omaha1944.html` in Chrome o Edge (serve internet per caricare Three.js da CDN).

| Tasto | Azione |
|---|---|
| WASD | Movimento |
| Shift | Corsa |
| C | Accovacciati |
| Mouse | Mira / spara |
| R | Ricarica |
| G | Granata |
| Esc | Pausa |

## Tecnologia
Un unico file HTML con Three.js r128, audio sintetizzato con WebAudio, AI alleata e nemica scritta a mano.
